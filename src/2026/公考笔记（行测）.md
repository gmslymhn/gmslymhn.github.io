## 言语理解与表达


::: info 逻辑填空 
 **核心：有逻辑、有对应。**

本模块大约为15个题，平时注意积累，积累词汇这部分是自身硬实力的部分体现。
注重前后关系、搭配，要有逻辑。
- 词的侧重
- 搭配对象（描写的谁？人还是物？名词还是形容词？）
- 轻重程度
- 感情色彩

注重并列关系，并列（两个一般为全并列关系，三个或以上为部分并列的递进关系）
遇到不懂的词咬文嚼字的看。
对应关系是相同还是相反。
保持平常心，一点破面。

:::


::: tip 片段阅读
**主题思维（主旨）：**注意主题是谁，谁是最重要的。

谁——干什么事——结果如何

主旨与选项一定有一个对象，要确定好对象是谁？

**结构思维：**每句话为基本单位，注意行文逻辑，例如是总分还是分总或是分总分。例如：北京+对策+解释。

主题思维和结构思维是本模块最重要的。

注意关联词：因此、所以、但是、然而......

①转折词。②对策词 找到这些词所描述的关键。

注意题干中的问题：（咬文嚼字的看）。

例如：
- 意在说明什么？ 意字代表作者想表达什么。
- 主要介绍什么？ 概括全文、核心内容、基本信息等。
- 强调了什么？     文本突出的部分。

言语理解是一个 宏观→微观 的过程。找出材料中作者想表达的，独到的见解，他自己的观点、想法。他对材料的评价。

本模块的重点在于理解。理解什么呢？理解作者表达的意图。理解什么呢？ 宏观→微观 ，注重行文结构。从对文章有一个整体的结构认识，到提炼最核心内容，它先讲了什么？又讲了什么？哪里是转折？那里是对策。？

有时候可以带入先选项看问题。例如认为某选项不对，思考一下如果是这一选项文中应该说什么？
:::


::: warning 标题填入题（主旨）
- ==确定对象==，讲的谁？
- 形式上更生动形象
:::

::: important 细节判断（大内存）
- 对每句进行总结
- 大内存缓存内容
:::

::: caution 语句排序
1. 确定首句，首句往往都是引子，引出话题，直接说各种专有名词的一般不是。
2. 确定捆绑，先说什么，在说什么。
3. 确定顺序，不一定紧靠，但有先后。
4. 确定尾句，总结。
ps：全程结合选项分析
:::

::: info 语句填空题（承上启下）
横线前后说的是什么，注意主体，是否有关联词。
注意：可适当默读一下，看看顺不顺。有的时候意思是到位的，但是不顺要注意。
:::

::: tip 接下来最可能讨论的是
1. 把握文章主要内容，“谁”是重点。
2. 重点分析尾句。
3. 提出问题→分析问题→解决问题
:::

:::  important 总结
1. 角度问题：角度要客观，不能有感情色彩去主观臆断。
2. 先看问题，再看题干。
3. 常见错误：①无中生有、②偷换概念、③偷换逻辑、④强加因果、⑤因果倒置、⑥与文意相悖。

同时，本模块最重要的是阅读理解，需要较快地阅读速度，这需要我们平时有意识地提高文章的阅读速度，大量的，快速的阅读。
:::

## 判断推理

::: info 图形推理 

位置规律：①平移、②旋转或翻转

样式规律：①加减异同、②黑白运算、③遍历

属性规律：①对称性、②曲直性、③开闭性

数量规律：①点、②面、③素、④线、⑤角、⑥加减

特殊规律：①功能元素、②图形间关系、③黑白快

空间类（空间想象类）：①空间重构、②立体拼合、③截面图、④三视图、⑤多面体折叠

图推心得：

1. 关注那些最特别的，排除思路时往往它是最重要的，突破点往往也是它。
2. 不止看题干图片，也可以看看选项图形，试着对比选项有什么不同。
3. 立体拼合，注意题中说的是外表面，外表面。
4. 注意看时间，实在没思路，选一个认为最有可能的，直接过。这玩意很看思路、直觉和灵感。不要死磕，当然不论是最后回头还是蒙一个，目的都是最大可能选对。不要不选就跳，涂卡的时候容易涂懵了。
5. 立体几何思维，空间想象力。
6. 笔画数  ps：一笔画一般能直接看出来
7. 直线与曲线，角度大小与角的多少。相同边或角。个数递进与个数差值，面对称与中心对称，相切、相割......
8. 多面体折叠注意图形的相对关系，以及部分面旋转重新组合。

相信相信的力量，抓住关键点，抓住特别点。

:::

::: important 定义判断
- 读的准：①谁？主客体，大前提。②方式+目的。③原因+结果。④修饰词
- 读的快：①定义所在句优先看。②补充说明重点看。
- 看选项：①对比选项。②细看名词、定义词。

注意看限制条件，先看问题，有时直接看问题都可以根据定义词判断结果。

多对比选项，找不同（同构思维）。
:::

::: tip 类比推理
- ①近义词、反义词。②比喻义、象征义。
- 逻辑关系：①全同、②并列、③包容、④交叉、⑤对应
- ①原材料、②工艺、③功能、④属性、⑤时间、⑥因果、⑦方式、目的

将题目的词拆分，同时不止横向比较，还有纵向比较。有时也可造句进行对比。

:::

::: warning 推理翻译

1.前推后（A→B）：

如果......就……；只要......就......

......就/则/都/一定......

2.后推前（B→A）：

只有......才......；除非......否则不......

ps：除非 A 否则 B     ⇔      ¬A→B

最后，无论怎样，都是以小推大。    小→大

A→B   ⇔   ¬B→¬A   ⇔   ¬A∨B


:::


::: important 论证综述
**论证三要素：论点、论据、论证。**

加强或削弱的对象都是论点，以论点为目的，这玩意是靶心。

削弱：①削弱论点、②拆桥、③削论据、④因果倒置、⑤他因削弱。

加强：①搭桥、②必要条件、③补充论据。

先看问题，再看/找论点，最后看全文。

同时，有时不必过于纠结选项。那选项牛头不对马嘴，不加强也不削弱，从全局看，有时正确选项很明显。==抓住论点不放==，以论点为目的。

:::

::: caution 一拖五

核心：抓住各个矛盾点，条件不只是题干给的，题干的各个条件相加也会导致新矛盾的产生。

- 适度推导：推出新结论，退到哪，是哪。
- **保持空间感**：有条理，有层次。
- 第一题：带入
- 后四题：①如问可能、不可能，带入；②如问必然，推导；③补充情况（条件），带入验证。
- 带入好限制项/自由项：空间感、条理感、层次感便在在这里。

注意把无条件限制的也列出来，无限制也分为一列，同时注意同质项。

”题不白做“，每题之间可能存在一定的连贯，或存在沿用。

:::

## 政治理论

::: info 政治理论

本模块注意题干中的内容，题干中的内容往往是本题的导向，目的，提示。

心中有党，成绩理想。实事求是。

可能的、不肯定的、不绝对的，是正确的概率更大，换句话说，太绝对的有可能是错的。注意绝对用词！！！

国外的都是不好的，国产的都是好的

- 问对的有几个？ 一般只会错一个
- 问错的有几个？一般只会错两个

没有结果导向（KPI），咱么不讲这玩意，还有以经济效益为导向。（唯经济论是错误的）

口号一般是对的，具体措施一般是错的

注意提示，叠BUFF的；主客体反了的；对应词互换了的。

注意题干，题干中的提示词，叠BUFF。

当出现多个并列名词时，可能有一个不符合要求。

本模块还会考马克思哲学，经济学，注意学习。

注意看时政，党的创新理论，方针政策。
:::

## 总结

::: caution 总结
1. 看好选项，不要想B选D，选择的同时选项勾画，也就是一题两个答案，防止大脑抽风了。
2. 仔细看问题，比如错误的是；正确的是；除......项外；要理清楚问题的意思。
3. 大胆假设，小心求证。
4. 论点、论据、论证。主旨、转折、对策。绝对的词、必须、应当。可能的词，非绝对的词。
5. 主旨、主体，讲的对象到底是谁？
6. 取舍
7. 词的侧重，轻重程度，搭配对象（谁？）。
8. 推理谬论：①明确主体是谁。②正确的选项，限制条件都会满足，少了限制条件无法证明对错（谬论）。
9. 错误有时是两个选项的部分内容互换了，或者是一个选项的部分内容反了。
10. 选项中给出多个并列名词时又可能是错的，因为它得对每个名词的描述都是对的才能行。
11. 秋风扫落叶：对点的时间内找出关键点。例如题干中给出的例子，并列的，分号分隔的，往往不是重点。把握行文结构，注重关键点。同时有取舍，落子无悔，选择之后就不要想着回头看了。
12. 先看问题，注重问题是要对的，还是要错的，是几倍，还是多几倍？是多少人还是多多少人？
